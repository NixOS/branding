# Wallpapers

`simple-dark-gray.svg` and `simple-blue.svg` are vector recreations of the 1920x1080 PNGs from 2016 in the archived [nixos-artwork](https://github.com/NixOS/nixos-artwork) repository, so that they can be rendered at any resolution.
The background gradients are fitted to the original PNGs, and the snowflake is the `nixos-logomark-white-flat-none` artifact from this repository.
